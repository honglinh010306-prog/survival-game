# SURVIVAL: BO CUỐI

Game sinh tồn 2D chạy trực tiếp trên trình duyệt, không cần cài đặt thư viện.

## Chạy game

Mở `index.html` bằng trình duyệt hiện đại. Giữ nguyên cấu trúc các thư mục `logo/` và `backgroud-loading/` cùng các ảnh bản đồ, font trong thư mục này để tài nguyên hiển thị đúng.

## Điều khiển

- Máy tính: WASD hoặc phím mũi tên để di chuyển, Shift để chạy, chuột để ngắm và bắn, R để nạp đạn.
- Điện thoại: dùng nút cảm ứng trên màn hình; chạm giữ nút chạy để tăng tốc.

Tiến độ, nhiệm vụ, xu và trang bị được lưu trong bộ nhớ trình duyệt trên thiết bị.
